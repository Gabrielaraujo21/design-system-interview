# 🚀 Comece aqui (nunca usou? é só seguir 3 passos)

## Passo 1 — Abra esta pasta na sua IDE
No Antigravity (ou Cursor, VS Code com agente, etc.): **Abrir pasta** → selecione a pasta desta skill (`design-system-interview`).

## Passo 2 — Cole este prompt no chat do agente
Copie o bloco abaixo inteiro e cole na conversa com a IA:

```
Você é o entrevistador de marca da V4. Leia o arquivo AGENTS.md desta pasta e siga-o à risca.

Comece agora a entrevista comigo, conversando de forma natural, uma pergunta por vez. As referências da marca são obrigatórias — insista nelas. Você preenche só a parte de TEXTO (manifesto, personas, tom de voz, palavras, diferenciais, CTA); não escolha cores, fontes nem tokens (isso é do designer).

Ao final, gere os arquivos brand-brief.md e o <Marca>.dsproj.json nesta pasta, e me explique o que fazer com eles. Depois pergunte se eu tenho a copy da landing page.

Pode começar com a primeira pergunta.
```

## Passo 3 — Responda as perguntas
A IA vai te entrevistar. Responda com sinceridade e **tenha 1 ou 2 sites de referência em mãos** (marcas que você admira). No final ela cria dois arquivos aqui na pasta:
- `brand-brief.md` — resumo da marca + referências
- `<Marca>.dsproj.json` — para abrir no builder

---

## Depois da entrevista
1. Abra o **Design System Builder**: https://gabrielaraujo21.github.io/design-system-builder/
2. 1ª etapa → **📂 Abrir projeto salvo** → selecione o `.dsproj.json` gerado
3. Escolha cores, fontes e tokens (a parte visual, do designer)
4. Exporte o Design System + o Prompt Lovable

> **Não achou o AGENTS.md?** Você abriu a pasta errada. Certifique-se de que abriu a pasta que contém os arquivos `AGENTS.md` e `SKILL.md`. Se ainda assim não pegar, arraste o arquivo `AGENTS.md` para dentro do chat antes de colar o prompt.
